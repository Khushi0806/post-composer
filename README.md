# Post Composer

A simple Post Composer application built using React and Vite.

## Features

- Enter a post using a textarea
- Select between Twitter and LinkedIn
- Twitter character limit: 280 characters
- LinkedIn character limit: 3000 characters
- Displays the current character count
- Displays an error message when the character limit is exceeded
- Clean and responsive user interface

## Technologies Used

- React
- JavaScript
- HTML
- CSS
- Vite
